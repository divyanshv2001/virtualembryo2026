# scNODE protocol and adaptation review

Pinned author commit ba55e8ddecfb74874047517952ab799326b4126d; MIT license. Eight relevant sources retained privately on D; small hash manifest records provenance. No author datasets or pretrained weights downloaded.

The [paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11373355/) combines VAE representation with neural ODE and dynamic regularization. The [author trainer](https://github.com/rsinghlab/scNODE/blob/ba55e8ddecfb74874047517952ab799326b4126d/optim/running.py) first reconstructs observed expression with stochastic latent samples, then jointly trains encoder, decoder and drift with observed expression Sinkhorn loss plus encoded/ODE latent Sinkhorn regularization. It uses Adam betas .95/.99. Default pretraining200steps, joint10x100, learning rate .001; extrapolation script beta.1 versus benchmark1. KL default0 is recorded rather than assuming a standard KL-regularized VAE.

[Loss code](https://github.com/rsinghlab/scNODE/blob/ba55e8ddecfb74874047517952ab799326b4126d/optim/loss_func.py) uses debiased tensorized p2 Sinkhorn, blur.05/scaling.5, averaging stages; observed training comparison samples200cells. [ODE code](https://github.com/rsinghlab/scNODE/blob/ba55e8ddecfb74874047517952ab799326b4126d/model/diff_solver.py) uses torchdiffeq with physical time values supplied by the caller; Euler and tolerance1e-5. Drift is autonomous. Author decoder uses ReLU output when hidden layers are supplied; encoder has mean and absolute-standard-deviation heads.

Local resource preflight uses synthetic32285genes,32latent,128width,6pastphysicalstages,batch32, five MSE pretraining steps then three joint steps for beta0/.1. It checks both arms' finite losses/component gradients and Windows peak working set below4GiB; it cannot establish biological accuracy or1000step runtime. Actual author whole-data pretraining is replaced with bounded minibatches; output std floor1e-5 is explicit. This is an adaptation, not faithful reproduction. No scoring or reward from synthetic checks.
