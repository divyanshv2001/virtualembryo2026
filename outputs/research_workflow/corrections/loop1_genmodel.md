## Composition-only and conditional-state estimators

Set pi_k=(1−w)p_Ak+w p_Bk. For each output row, draw k~Categorical(pi), then s~Categorical(q_Ak,q_Bk), with q_Ak=(1−w)p_Ak/pi_k and q_Bk=w p_Bk/pi_k. A zero pi_k is omitted. Draw donor embryo and row as above. Use a fixed PCG64 seed recorded in the manifest, and reuse exactly the same donor ledger for both methods; output row count N is frozen before assessment.

Composition-only raw output is v_comp=X_sj. For strata present at both endpoints define mu_tk=(1−w)mu_Ak+w mu_Bk and freeze shrinkage lambda=1/2 without selection. Conditional-state raw output is

v_state = mu_sk + (X_sj−mu_sk) + lambda(mu_tk−mu_sk).

This is a complete whole-row residual sampler, not independent per-gene sampling or fitted full covariance. Conditional on s,k, its untransformed mean is (1−lambda)mu_sk+lambda mu_tk. Its overall stratum mean before the output map is (1−lambda)[q_Ak mu_Ak+q_Bk mu_Bk]+lambda mu_tk. Composition-only has the bracketed mean. Thus the comparison changes conditional means while holding stratum weights and residual donor rows fixed. With lambda=1 the conditional mean would equal mu_tk; choosing 1/2 conservatively shrinks that hypothesis and makes the primary contrast a specified half-shift, not the optimum shift.

For a stratum observed at only one endpoint, set its shift to zero. Its weight fades or appears through convex endpoint weights; its state remains the observed endpoint distribution. Do not manufacture the missing endpoint mean. An entirely novel target state has zero modeled support: neither UNKNOWN nor continuous shifts establish its biology. Record this limitation and report novel-state diagnostics after assessment only; they cannot trigger confirmatory refitting on the same target.

## Output validity and paired geometry

Apply one frozen map F to both raw outputs. If the verified assay transform is x=log(1+L r/sum(r)), with a known constant L, compute u_g=max(expm1(max(v_g,0)),0), then F(v)_g=log(1+L u_g/sum(u)) when sum(u)>0. For an all-zero u, preserve the zero row and flag it rather than inventing expression; such a row requires the documented assay's zero-row policy. Float64 intermediate exponentiation is used, with explicit overflow rejection rather than silent saturation. This gives nonnegative log-normalized output under that documented transform. If training normalization is different, this map is inapplicable: implement its documented inverse/forward pair or stop. Finite/nonnegative validation alone does not establish normalization. If no normalization metadata exist, only a format-valid clipped illustration can be produced, explicitly excluded from biological assessment.

Clipping removes negative proposed log values and changes means, zeros and covariance; renormalization also couples genes and changes covariance. The affine estimator preserves donor covariance only before F. Report fraction of clipped entries, zero rows, and mean-shift discrepancy after F. Never claim covariance preservation after this transformation. Composition-only undergoes the same F; test that it round-trips verified training rows within numerical tolerance before use. Disable this normalized-output route if that contract fails.

For every donor j, output C_sj from that same row, without translation, interpolation, nearest-neighbor rematching or registration. Both methods use identical output coordinates and donor assignments. This pairing is deterministic once the ledger is fixed; it preserves donor correspondence and isolates an expression contrast. It does not predict an intermediate embryo's shape or guarantee correct local organization. Neighborhood expression metrics can change because expression at fixed positions changes. Shapes and spatial guardrails remain descriptive until the scorer contract exists; duplicated donors and mixed endpoint frames must be disclosed.

## Bounds, assumptions and verification

Store endpoint matrices in float32 or access backed chunks; compute per-stratum sums in float64 with O(Kd) memory. Stream output in fixed chunks of B=256 rows. Dense working/output-chunk memory is O(Bd+Kd); reading both full endpoints would additionally cost O((n_A+n_B)d). There is no d×d covariance matrix, eigendecomposition or full transcriptome covariance fit. This recipe concerns a roughly 500-gene panel; extending to T1 would require a separate measured-domain and streaming design, not a 32,285² matrix.

Weakest assumptions: endpoint labels define useful comparable measured strata; linear mixing of endpoint proportions is an adequate proxy; shared-stratum log-expression centers change approximately linearly over this interval; donor residual shapes are sufficiently reusable; the documented normalization is invertible for nonzero rows.
