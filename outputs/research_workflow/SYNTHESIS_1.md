## Surviving scientific question

Snapshot prediction concerns observed distributions conditional on stage, assay and capture, not identified ancestry. p_t(X,C)=Σ_kπ_k(t)p_t(X,C|k) is statistical bookkeeping, not an identified causal decomposition. Capture/annotation drift can mimic composition/state changes. The mandatory endpoint-mixture baseline tests whether a frozen training-only mean shift helps this narrow interpolation proxy. It does not validate novel future populations, extrapolation, morphogenesis or unseen-gene transfer.

Training-only annotations must be comparable. Missing normalization/labels stop the recipe; target values never construct strata. Output clipping/renormalization alters covariance. Donor pairing preserves identity, not geometry. Equal-embryo aggregation is meaningful only when manifests expose independent samples. The deterministic illustration tests arithmetic, normalization, overflow, pairing, support, power scaling and access transitions; no biological array was fitted.
